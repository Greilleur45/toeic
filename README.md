# TOEIC 850

Appli de révision personnelle pour le TOEIC du **9 avril 2027** (objectif 850, avec Global Exam en parallèle).

- **Ce soir** : séance de 10 min en un bouton (règle de la semaine, questions, révisions espacées, mots nouveaux).
- **Apprendre** : 8 fiches de grammaire + 240 questions, 300 mots business (saisie au clavier pour l'orthographe), 20 textes Parties 6/7 chronométrés, carnet d'erreurs.
- **Global Exam** : heures vers les 27 h, meilleure note par module (≥ 70 %), modules à refaire, courbe des tests blancs.
- **Progrès** : maîtrise par thème, série, calendrier.

Appli web installable (PWA), fonctionne hors ligne. Les données ne sont **pas** dans ce repo : elles sont synchronisées dans le repo privé `toeic-data/data.json` via un jeton GitHub stocké uniquement sur tes appareils.

Contenu (original) : `js/content/`. Vérification : `node tools/check-content.mjs`.
